Bundled fonts

The Corpus interface bundles these families so the local application does not
depend on a font CDN at runtime:

- Cormorant Garamond — https://github.com/google/fonts/tree/main/ofl/cormorantgaramond
- IBM Plex Mono — https://github.com/google/fonts/tree/main/ofl/ibmplexmono
- Lora — https://github.com/google/fonts/tree/main/ofl/lora

The fonts are distributed under the SIL Open Font License, version 1.1. The
license text is available at https://scripts.sil.org/OFL and in the project
source repositories above.
